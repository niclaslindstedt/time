type: Added
title: Sync to your own server
---

Your hours can now sync to a storage server you run yourself, end-to-end encrypted so the server holds them without being able to read them. Pair the first device with the code from the server's console and keep the recovery key it shows; add the next one by scanning the QR under Settings → Add a device. Changes from another device arrive within moments. [Learn more](feature:cloud-sync)
