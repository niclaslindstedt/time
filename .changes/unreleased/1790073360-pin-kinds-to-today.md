title: Keep the Today screen to the kinds you actually use
---

Each row on the Today screen now ends in a **···** holding the kinds the project has but does not show, along with **Custom**. Every break type and kind of work carries a **Show on Today** answer — the star in the project form, or the switch in the form a held pill opens — so a project can grow a dozen of them without the screen growing a dozen buttons. Everything already in a project stays shown. [Learn more](feature:today)
