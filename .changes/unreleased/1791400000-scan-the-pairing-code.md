title: Scan the pairing code in the phone app
---

In the phone app, connecting to your own server no longer means copying the pairing code across: tap **Scan** on the pairing sheet and point the phone at the QR code the server or another of your devices shows. The camera is asked for only then, and no picture is kept. Pasting the code still works, and if the camera is off for the app, the sheet says how to allow it or paste instead.
